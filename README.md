# 旅の支出メモ (Trip Expense App)

旅行ごとの予算と支出をすっきりと管理できる、スマートフォンに最適化した北欧ミニマルスタイルのWebアプリケーションです。

## 🌟 主な特徴

- **北欧ミニマルデザイン**: セージグリーンとサンドベージュを基調とした、温かみのある落ち着いた配色。
- **旅行（イベント）管理**: 複数の旅行を作成し、それぞれの予算と日程、メモを設定可能。
- **進捗ゲージとグラフ**: 予算に対する支出額をリアルタイムでバー表示。超過時はアラートでお知らせ。カテゴリ別の支出は、美しくアニメーションするカスタム円グラフ（SVG）で直感的に確認できます。
- **スマートな支出登録**: 金額、日付、カテゴリ（食費、交通、宿泊、観光、買い物、その他）、支払方法（現金、カード、電子マネー）、メモを数タップで記録。日付ごとに自動でグルーピングされます。
- **ブラウザへのローカル保存**: データはブラウザの `localStorage` に完全に安全に保存されます（サーバー送信なし）。
- **PDFエクスポート (印刷)**: 印刷・PDF用に最適化されたレイアウト（明細テーブル、サマリー、カテゴリ割合）を、ブラウザ標準の印刷機能を使ってA4用紙やPDFとして美しく出力できます。
- **データバックアップ**: すべてのデータを JSON ファイルとしてエクスポート・インポートできます。

---

## 🛠️ 技術スタック

- **フレームワーク**: React (TypeScript)
- **ビルドツール**: Vite
- **スタイリング**: Vanilla CSS + CSS Variables (`src/index.css`)
- **アイコン**: Lucide React
- **永続化**: `localStorage`

---

## 🚀 起動方法

以下のコマンドを実行して開発用サーバーを立ち上げます：

```bash
# 依存関係のインストール (初回のみ)
npm install

# 開発用サーバーの起動
npm run dev
```

起動後、ターミナルに表示されるURL（例: `http://localhost:5174/`）にブラウザでアクセスしてください。
